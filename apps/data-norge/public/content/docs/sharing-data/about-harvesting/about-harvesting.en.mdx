# Get started with harvesting

Do you have your own data catalogue, and wish to share the information on data.norge.no? Through the administration solution for harvesting endpoints in the Norwegian data catalogue, organisations can register the harvesting endpoints for their catalogues.

## The administration solution for harvesting endpoints

For organisations that have their own catalogues and wish to manage them locally, sharing the data is still worthwhile. The Norwegian Digitalisation Agency wants to work towards the "ONCE ONLY" principle, and encourages all public sector organisations to share data.

[Log in to the administration solution for harvesting endpoints](https://admin.fellesdatakatalog.digdir.no/)

We currently support harvesting of descriptions of datasets, data services and data catalogues following the DCAT-AP-NO standard, concept descriptions following the SKOS-AP-NO-Begrep standard, information model descriptions following the ModellDCAT-AP-NO specification, and descriptions of services and events following the CPSV-AP-NO specification.

Read more about the standards here:

- Standard for describing datasets, data services and data catalogues: [DCAT-AP-NO](https://data.norge.no/specification/dcat-ap-no)
- Standard for describing concepts: [SKOS-AP-NO-Begrep](https://data.norge.no/specification/skos-ap-no-begrep)
- Specification for describing information models: [ModellDCAT-AP-NO](https://data.norge.no/specification/modelldcat-ap-no)
- Specification for describing services and events: [CPSV-AP-NO](https://informasjonsforvaltning.github.io/cpsv-ap-no/)

<Alert>
  **Note**: You need the correct access rights to register a data source on behalf of your organisation. Read more about
  [getting started with registration](/docs/sharing-data/about-registration).
</Alert>

## 1) Add a data source

Click the "Legg til datakilde" (Add data source) button to add a new data source for your organisation.

![The administration solution showing a list of data sources and a button labelled "Legg til datakilde"](/images/content/Legg_til_datakilde_hosting_e7b2615f43.png)

## 2) Fill in the form

Fill in the fields "Utgiver" (publisher), "Katalog" (catalogue), "Datakildetype" (data source type), "Format" (format), "Navn på datakilde" (data source name) and "URL til datakilde" (data source URL).

![Form with a button labelled "Lagre"](/images/content/fyll_ut_skjema_og_lagre_0a23c02aa1.png)

Click the "Lagre" (Save) button. The new data source should now appear in the administration solution.

## 3) Click the "Høst" button

![Entry for a data source with the "Høst" button](/images/content/Host_datakilde_32e39ac950.png)

A message confirms that the harvest request has been sent.

![Message confirming that the harvest request has been sent](/images/content/Hosteforesporsel_sendt_dfe7086a1e.png)

The harvesting process can take a while, depending on the size of your catalogue, before the result is published on [data.norge.no](https://data.norge.no).

Thank you for sharing data!
